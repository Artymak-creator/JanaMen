# Тест маршрута «сотрудник → руководитель → HR» (3 аккаунта)

Подготовка: SQL выполнен, роли назначены (`supabase/02_assign_roles_TEMPLATE.sql`), `npm run dev` запущен.
Откройте три окна: обычное и два в режиме инкогнито (или три браузера).

| # | Кто | Действие | Ожидаемый результат |
|---|-----|----------|---------------------|
| 1 | Сотрудник | Войти, «Ежегодный отпуск» → оплачиваемый, выбрать период короче остатка | Видны длительность и остаток, заявка отправляется |
| 2 | Сотрудник | Попробовать период длиннее остатка | Отправка заблокирована |
| 3 | Сотрудник | Тип «без содержания» | Остаток не требуется, заявка создаётся |
| 4 | Руководитель | Открыть список заявок | Видит только заявки своих сотрудников; согласовывает с комментарием |
| 5 | HR | Открыть заявки | Видит заявку после согласования руководителем, принимает решение |
| 6 | Сотрудник | Обновить страницу | Статус и комментарии руководителя и HR, подпись и время HR; таймлайн истории |
| 7 | Проверка БД | Table Editor → profiles | Остаток уменьшился на число дней одобренной оплачиваемой заявки; у «без содержания» не изменился |
| 8 | HR | Попробовать подать заявку | Форма скрыта (и база отклоняет) |
| 9 | Руководитель | Подать свою заявку | Уходит сразу в HR (если у него нет manager_id) |
| 10 | HR | Добавить событие в календарь | Сотрудник видит его в календаре и в «Ближайших событиях» |

Если шаг не прошёл — пришлите текст ошибки и номер шага.
