# JanaМен / JanaPost — схема проекта

## Основные функции

- Supabase Auth для входа и регистрации.
- Роли: `employee`, `manager`, `hr`.
- Заявки сохраняются в `public.requests`.
- Согласование: сотрудник → назначенный руководитель → HR.
- HR фиксирует финальное решение и дату подписи.
- Для ежегодного отпуска есть тип `paid` / `unpaid`.
- Остаток оплачиваемых дней хранится в `public.profiles.annual_leave_days_remaining`; дни списываются в базе после финального одобрения HR.
- `Jana Pulse` пока хранит настроение в браузере.
- Бело-зелёная тема с режимами light/dark.

## Новая база Supabase

Для пустого нового проекта выполните целиком `supabase/00_FRESH_DATABASE.sql`. Он создаёт базовые таблицы и добавляет функции/политики остальных модулей. Не запускайте вместо него `00_ALL_IN_ONE.sql` на пустой базе — этот файл предполагает существование основных таблиц.

Затем создайте `.env` на основе `.env.example` и вставьте URL и публичный ключ нового Supabase-проекта. Зарегистрируйте три тестовых пользователя и используйте `supabase/02_assign_roles_TEMPLATE.sql`, чтобы назначить роли, руководителя и подтверждённый остаток дней.
