# JanaМен / JanaPost — сверка с уточнённым ТЗ

| Требование | Реализация в обновлённом проекте | Что ещё обязательно сделать |
|---|---|---|
| Три роли: сотрудник, руководитель, HR | Роли `employee`, `manager`, `hr` считываются из `public.profiles.role`. | После миграции назначить реальные роли аккаунтам в Supabase. |
| Заявку могут подать все, кроме HR | Форма доступна сотруднику и руководителю; для HR скрыта. Триггер базы запрещает создание заявки HR. | Проверить тестовыми аккаунтами. |
| Последовательность «сотрудник → руководитель → HR» | Сотрудник отправляет заявку назначенному руководителю. Руководитель согласовывает и передаёт её HR. HR принимает итоговое решение и фиксирует подпись. | В `profiles.manager_id` назначить каждому сотруднику его руководителя. |
| Руководитель также может подавать заявки | Руководитель может создать собственную заявку. Если указан его руководитель — заявка идёт ему; если нет — сразу в HR. | Это правило принято как практическое допущение, потому что в исходной заметке не указан руководитель для самого руководителя. |
| Ежегодный оплачиваемый отпуск | При выборе дат показываются количество дней и текущий доступный остаток; система не принимает период длиннее остатка. | HR должен внести актуальный баланс в `profiles.annual_leave_days_remaining`. |
| Отпуск без содержания | Есть отдельный тип «Отпуск без сохранения заработной платы»; баланс оплачиваемых дней не расходуется. | Сверить название и правила с формулировкой официального ТЗ/компании. |
| Списание дней после одобрения | После финального одобрения HR серверная функция списывает дни в той же транзакции с проверкой актуального остатка. | Проверить на тестовой заявке в существующем Supabase-проекте. |
| Комментарий руководителя и HR | Комментарии двух этапов отображаются раздельно. | Проверить фактическое сохранение после выполнения миграции. |
| Подпись HR и время | `hr_signed_by` и `hr_signed_at` назначаются на сервере при финальном решении. | Проверить обновление строк в Supabase Table Editor. |
| Косметика: бело-зелёный стиль JanaPost | Основная палитра обновлена для светлой/тёмной темы, формы и HR-ассистента. | Визуально просмотреть на своём компьютере и согласовать оттенки с брендом, если есть фирменные цвета. |
